Keep selenite delivery artwork neutral and environmental illumination separate.

**Why:** The intended material system must eventually respond to its environment independently; baking warm/lavender/cyan illumination into the texture would prevent that separation.

**How to apply:** Preserve the canonical neutral material when creating derivatives. Obtain environmental colors through compositing with the stationary environment, not recolored texture artwork.

The crystalline surface is a thin optical film whose density comes from population and connectivity. Growth has a lateral bias without a clean wipe frontier. Both navigation directions use the same material physics; dissolution breaks continuity rather than reversing formation.

**Why:** The user's definitive material specification supersedes the earlier top-to-bottom/bottom-to-top traveling-sheet grammar. The intended perception is that the Mirror surface crystallizes and clears, not that a mineral photograph passes over it.

**How to apply:** Preserve this material model in future iterations. Artwork supplies microscopic vocabulary, not a full-screen opaque panel.

The user physically validated concealed substitution, destination preparation, touch blocking, cleanup, rapid input, reduced motion, scroll reset, and persistence on Android. Preserve that navigation machinery when revising material behavior.

**Why:** The user says the stable architecture is already proven on physical hardware; visual revisions are not a reason to rebuild it.

**How to apply:** Keep optical experiments bounded and retain existing sequencing safeguards.

The user physically validated the 2,100 ms lifecycle and 62% concealed handoff on the Blackview, rating the hidden substitution 10/10. Do not retune these based on desktop/browser feel alone.

**Why:** The user says the duration feels correct and the concealed handoff works extremely well. This newer physical finding supersedes the earlier speculative shorter production range.

**How to apply:** Preserve these values during bounded material refinements unless the user requests a timing change or a demonstrated regression requires correction. Physical Android observation remains the judge of material quality.

The physical review found generic line-segment identity/endpoint joins, weak Luminous-to-Dense differentiation, and some hitching, while confirming distributed growth, environmental color transmission, gaze-local transformation, and seamless destination reveal.

**Why:** The requested refinement targets material identity, not a transition redesign or broad performance pass.

**How to apply:** Preserve successful spatial/navigation behavior and judge improved fiber identity and directional scattering on hardware rather than assuming a browser preview resolves those perceptual findings.

Optional orientation input belongs to the shared glass/mineral optical response, never crystal nucleation, geometry, or navigation. Do not introduce an automatic or intrusive sensor permission experience.

**Why:** The user wants restrained evidence of a pristine virtual reflective surface, not a gyroscope effect or a new permission flow.

**How to apply:** Stay neutral when sensor input is unavailable, unreliable, denied, disabled, or reduced motion is requested. Permission-gated access requires an explicit user gesture; report that requirement instead of inventing permission UI.

Feature-detect sensor permission APIs rather than assuming only Safari/iOS exposes them; the available Chromium browser also exposed an orientation permission method.

**Why:** Browser validation encountered a permission-gated API in Chromium, invalidating an OS-only capability assumption.

**How to apply:** Test both gated and non-gated paths; neither may control navigation correctness. Browser sensor simulation does not prove physical sensor feel.

A polygon-clipped material establishes a stacking context. A soft-light child blends with other material layers inside that context, not directly with the environment behind it. Multiple translucent source layers also compound coverage.

**Why:** A strong secondary texture layer made the luminous phase nearly gray despite a low-opacity primary layer in a mobile browser capture.

**How to apply:** Judge combined coverage, not a single layer's opacity. Keep secondary strata treatment restrained so actual environmental color can transmit through the composite.
