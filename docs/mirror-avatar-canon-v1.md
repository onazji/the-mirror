# Mirror Avatar Canon v1

Mirror avatars are behavioral silhouettes, not characters. Psychological state
is conveyed through posture, weight distribution, tension, orientation, and
hand placement. Identity markers—including facial features, clothing,
ethnicity, hairstyle, age, and accessories—are intentionally omitted so that
attention remains on the state itself rather than the individual. Emotional
nuance beyond posture is expressed through the Mirror Light System.

The avatar variant is an independent local preference. It does not participate
in state calculation, scoring, reflection history, or reveal animation. The
state-specific avatar asset is selected only at reveal time. The independent
Mirror Light Behavior layer attaches separately beneath it during the reveal.
